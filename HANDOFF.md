## What Was Built

### Backend (NestJS)
- Auth: JWT access + refresh tokens, bcrypt hashing, role-based guards
- 10 modules: Auth, Users, Units, Maintenance, Payments, Announcements, Guests, Notifications, Uploads, Health
- Roles: RESIDENT, ADMIN, SECURITY
- Prisma ORM with 11 models
- S3 presigned URLs for file uploads (ID docs, maintenance photos)
- Guest QR code generation + gate scan flow
- FCM device token registration
- Swagger docs at /api/docs

### Admin Dashboard (React)
- React 19 + Vite + TanStack Router/Query/Table
- 8 sections: Residents, Units, Billing, Maintenance, Gate, Announcements, Staff, Reports
- shadcn/ui components, Tailwind CSS v4
- Design: navy (#1B3A6B) + gold (#C9A96E) theme

### Mobile App (Flutter)
- Flutter + Riverpod + go_router
- iOS + Android
- Resident screens: Auth, Home, Payments, Gate QR, Maintenance, Community, Unit, Profile, Multi-unit
- Security guard screens: Login, QR Scanner, Visitor Log
- Dark mode supported
- Push notifications (FCM)
- Biometric auth

## Security
- 9 CRITICAL issues found in code review — all fixed before deploy
- JWT secret fallbacks removed (startup fails if env vars missing)
- CORS restricted to allowed origins
- All admin routes require ADMIN role
- S3 uploads scoped to user prefix + 20MB limit
- GoRouter auth guard on all mobile screens
- Guest pass USED status enforced (no replay)
